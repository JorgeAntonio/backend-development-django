# Backend Sessions · Python & Django

Landing page inspired by Guillermo Rauch's portfolio to navigate the material for the Backend Sessions course. It links to interactive Reveal.js slide decks that introduce the fundamentals of backend development, HTTP, and hands-on cURL practice.

## Overview
- **Homepage:** Minimalist article list styled with the Vercel palette and Inter typography.
- **Slides:** Reveal.js decks for "Fundamentos de la Web" and the cURL workshop.
- **Workshops:** Practical exercises to explore APIs, status codes, and terminal workflows.

## Tech Stack
- HTML5 & modern CSS (custom design)
- [Reveal.js](https://revealjs.com/) for presentations
- [Highlight.js](https://highlightjs.org/) for code snippets

## Getting Started
1. Clone or download this repository.
2. Open `index.html` in your browser to access the Guillermo-style portfolio landing page.
3. Use the article links to jump into the session decks.

## Sessions
- [Sesión 1 · Fundamentos de la Web](sessions/fundamentals/fundamentals.html) — conceptos clave de HTTP, APIs y status codes.
- [Sesión 1 · Fundamentos & cURL](sessions/fundamentals/curl.html) — comandos prácticos para interactuar con APIs desde la terminal.
