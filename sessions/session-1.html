Backend Sessions

Sesión 1 · Fundamentos

HTTP, arquitectura cliente-servidor y APIs públicas

Inicio Plan GitHub

Objetivo

Comprender cómo viaja una petición web, los elementos de HTTP y la diferencia entre HTML tradicional y APIs orientadas a JSON.

Instructor

Jorge Antonio Del Aguila

Duración

3 horas · 19/11

Agenda

  • Arquitectura cliente-servidor y flujo navegador → servidor → base de datos.
  • HTTP/HTTPS: métodos, headers, body y status codes fundamentales.
  • JSON vs HTML y cuándo servir cada formato.
  • DevTools como herramienta para inspeccionar peticiones.
  • Ejercicios con JSONPlaceholder y PokeAPI usando navegador y cURL.

Recursos utilizados

  • Slides · Fundamentos de la Web

    Presentación Reveal.js que cubre HTTP, APIs, status codes y analogías clave.

    Abrir

  • Workshop · Fundamentos & cURL

    Laboratorio guiado para hacer peticiones reales desde la terminal.

    Abrir

Resultado

Los estudiantes terminan la sesión entendiendo cómo se construye una respuesta backend, identifican status codes comunes y saben inspeccionar una petición real antes de introducir Django.
