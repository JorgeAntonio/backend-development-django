Backend Sessions

Sobre el Curso

Programa profesional de 24 horas · Python, Django, DRF y Deploy

Inicio GitHub

Contenido

Es un programa intensivo de 24 horas que replica el flujo real de un equipo backend: investigación, construcción, pruebas, despliegue y operación. Cada sesión entrega un entregable (slides, workshop o repo) y se conecta con la siguiente para construir un proyecto completo.

Perfil

Para devs que ya programan

Ideal para desarrolladores con bases en Python/JS que quieren profesionalizar su stack backend o para frontend devs que migran al server side.

Resultados

Skillset completo

Saldrás con un backend funcional, API REST documentada, pipelines Git y un playbook de despliegue en AWS listo para producción.

Formato

8 sesiones · 3 h c/u

Workshops guiados, live-coding y retos individuales. Todo el material queda publicado en este sitio.

Herramientas y Tecnologías

Lenguajes & Core

  • Python 3.12
  • Shell / cURL
  • HTML + JSON (para entender el intercambio)

Frameworks

  • Django 5.x
  • Django REST Framework
  • pytest-django / unittest

Datos

  • SQLite para prototipos
  • PostgreSQL para producción
  • JSONField, búsquedas full-text

Tooling & Deploy

  • Git + GitHub Flow
  • GitHub Actions (CI)
  • AWS EC2 · Nginx · Gunicorn · Let’s Encrypt

Metodología

  • Mini briefs al iniciar cada sesión para contextualizar el reto.
  • Live coding + pair programming para ver cómo se resuelven problemas en tiempo real.
  • Retrospectiva y checklist al cierre para preparar la siguiente sesión.
  • Repositorio centralizado con slides, workshops y scripts de deploy.
